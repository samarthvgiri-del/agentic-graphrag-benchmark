# Graph Databases and Knowledge Graphs

## What is a Graph Database?

A graph database is a database that uses graph structures with nodes, edges,
and properties to represent and store data. Unlike relational databases that
use tables, graph databases excel at handling highly connected data.

## TigerGraph

TigerGraph is a distributed graph database designed for enterprise-scale
analytics. It uses GSQL, a SQL-like query language optimized for graph
traversal. TigerGraph can process billions of vertices and edges in
real-time, making it suitable for fraud detection, supply chain analysis,
and recommendation systems.

## Knowledge Graphs

A knowledge graph represents information as a network of entities and their
relationships. When combined with RAG (GraphRAG), knowledge graphs provide
structured context that goes beyond simple text similarity, enabling
multi-hop reasoning and relationship-aware retrieval.
